# 公平设备调度：设计概览

本文档描述多任务设备池的通用调度原则，不包含特定平台的账号、页面或操作细节。

## 目标

- 在设备能力上限内分配任务；
- 避免单个账户或任务长期占用设备；
- 设备异常时快速降权或排除；
- 让调度结果可解释、可观测、可测试。

## 评分因素

调度器可以综合考虑当前负载、历史任务耗时、设备健康状态、最近失败次数、账户冷却时间、任务优先级、设备能力上限和队列长度。

调度器只负责选择可用执行资源，不负责确认业务事实。业务确认仍由订单状态机、匹配器和审计账本完成。

## 安全边界

设备操作必须经过 actor 串行化和授权检查。设备离线、任务超时或结果不明确时，调度器应停止继续分配并生成健康事件，而不是猜测任务已成功。
