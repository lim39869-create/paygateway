# 设备自动化与个人通道：学习概览

> 本文档只保留架构和工程实践概览，不提供特定平台的收款操作、设备坐标、账号配置、连接参数或规避平台限制的方法。相关实现代码保留在仓库中，供获得授权的学习和测试使用。

## 目标

个人通道是一个可选的实验性适配器，用于研究如何把外部设备事件接入订单状态机。它复用统一的订单、幂等、异常池、账本和告警基础设施，不改变商家通道的核心流程。

## 工程边界

- 设备访问通过受控的设备管理层封装，业务代码不直接散落调用设备命令。
- 设备事件必须经过来源认证、时间窗口、金额校验和幂等去重。
- 设备离线、解析失败、状态冲突和无法确认的事件进入异常池，不自动入账。
- 设备调度使用串行化访问、租约、健康状态和负载感知，避免多个任务同时操作同一设备。
- 任何个人账户、支付平台或设备的接入，都必须获得账户所有者授权并遵守适用的平台规则。

## 保留的通用实践

- DeviceActor/租约式设备访问串行化；
- 设备离线与任务超时的安全降级；
- 事件指纹、窗口匹配和重复回调幂等；
- 设备负载驱动的任务调度；
- 账本哈希链、签名和异常事件留痕；
- 运行状态、健康指标和告警。
