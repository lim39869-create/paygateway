# Security Policy

Please do not disclose credentials, private keys, payment data, personal data,
or production endpoints in a public issue.

For a suspected security issue, contact the maintainers privately with the
affected version or commit, a minimal reproduction, the impact, and logs with
secrets and personal data removed.

This project is a learning and research reference. Deployers are responsible
for authorization, platform terms, payment compliance, data protection, and
operational security in their own environment.
