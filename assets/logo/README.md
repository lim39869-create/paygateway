# PayGateway Brand Assets

The mark represents three ideas in one restrained route glyph:

- converging rails for a plugin-based gateway;
- a shared spine for order and channel orchestration;
- the green seam for a verifiable ledger trail.

The assets use the admin design tokens `#7170FF`, `#22A069`, `#0D0D0F`, and
`#FAFAFA`. Keep the mark clear of QR codes, payment-card illustrations, and
third-party platform logos when creating derivatives.

Files:

- `paygateway-mark.svg`: dark-background mark;
- `paygateway-mark-light.svg`: light-background mark;
- `paygateway-wordmark.svg`: README and documentation lockup;
- `favicon.svg`: compact browser/app icon.
